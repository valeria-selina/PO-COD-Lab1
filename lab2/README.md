# PO-COD-Lab2

Лабораторная работа № 2 «Совместная работа в GitHub».

## Цель работы

Освоить цикл GitHub Flow. Изменения вносятся в отдельную ветку, проверяются в Pull Request и после проверки объединяются с основной веткой.

Выполнила Селина В. В., группа ИКПИ-33.

## Порядок работы

1. Создать ветку `po_cod_changes` от основной ветки проекта.
2. Добавить раздел «Цель работы» и зафиксировать правку коммитом `Add goal section`.
3. Добавить сведения об исполнителе и зафиксировать правку коммитом `Add authors`.
4. Открыть Pull Request из `po_cod_changes` в основную ветку. В отчёте основной веткой является `main`.
5. На вкладке **Files changed** проверить разницу, затем слить Pull Request и проверить итоговый README в основной ветке. После слияния рабочую ветку можно удалить.
