## ЛР № 1. Система управления версиями Git. Сервис GitHub

Цель работы — освоить локальную историю Git, синхронизацию с GitHub и работу с ветками. Практический файл этой работы — `README.md`.

В рабочей копии `git status --short` показывает состояние файла. Новый файл отображается с `??`, после `git add README.md` — с `A` в первом столбце, а правка отслеживаемого файла до индексации — с `M` во втором столбце. После коммита `git status --short` выводит пустой результат, если других изменений в рабочей копии нет.

```bash
git clone https://github.com/valeria-selina/PO-COD-Lab1.git
cd PO-COD-Lab1
git status --short
git remote -v
git log --oneline --graph --all
```

Для отдельного изменения README в отчёте использовалась ветка `feature-readme`. После редактирования файл индексируется командой `git add README.md` и фиксируется командой `git commit`. Затем изменения можно объединить с основной веткой командой `git merge feature-readme`. Для синхронизации с GitHub используются `git pull --ff-only` и `git push`.
